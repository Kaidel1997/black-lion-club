# Black Lion Fencing Club

Адаптивный макет нового сайта клуба для GitHub Pages. Чистые HTML, CSS и JavaScript; сборка и платные сервисы не нужны.

## Редактирование

- `index.html` — тексты, направления, тренеры, расписание и контакты.
- `style.css` — палитра, шрифты, сетки и мобильная версия.
- `script.js` — фильтрация расписания, меню и галерея с увеличением фотографий.
- `assets/originals/` — все 24 найденных уникальных оригинала: 21 JPEG (включая изображение расписания) и 3 SVG.
- `assets/sources.json` — исходные адреса, размеры файлов и SHA-256.

Открыть `index.html` в браузере либо обслуживать папку любым статическим HTTP-сервером. Все пути относительные и поддерживают адрес GitHub Pages вида `/black-lion-club/`.

## Публикация

GitHub → Settings → Pages → Deploy from a branch → main → / (root). Доступность Pages для приватного репозитория зависит от плана GitHub. Не менять приватность без отдельного решения владельца.

Содержание и изображения: https://blacklionclub.tilda.ws/, получены 17.09.2026. Имена и соответствие портретов проверены по исходной разметке. Фотографии принадлежат их владельцам; перенос выполнен по поручению владельца сайта. Новые заголовки и короткие описания направлений — редакторское предложение ИИ, а не цитаты.

Расписание перенесено из текстового раздела исходного сайта. Его актуальность, как и адрес, возрастные ограничения и доступность экипировки, нужно подтвердить у клуба. Старая картинка расписания сохранена в архиве, но не используется как источник актуальной информации. Цены не выдуманы.
